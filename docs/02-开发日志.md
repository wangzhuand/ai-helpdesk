## 踩坑记录（面试素材，随做随记）

1. **主类包名拼错 `hepldesk` → 接口 404**：`@SpringBootApplication` 的 `@ComponentScan` 只扫描主类所在包及子包；所有业务类必须放在主类包正下方。已修正为 `com.example.helpdesk`。
2. **Spring Initializr 向导无 3.x 选项**：向导联网 start.spring.io（被墙）且默认只给最新 4.x；改用手动 Maven + pom 写死 parent `3.5.3` 走阿里云镜像解决。生态组件（MyBatis-Plus/Spring AI）对 4.x 适配未跟上，项目锁定 3.5.x。
3. **LF/CRLF 换行警告**：Windows 与 Git 换行符差异，无害；可用 `.gitattributes`（`* text=auto`）统一，暂未加。
4. **登录报"密码错误"真相**：`CommandLineRunner` 只在应用启动时执行一次，写完 DataInitializer 没彻底重启（热重载不算），导致占位密码没被替换。教训：加了"启动时初始化"类代码，必须完全停掉进程再全新启动。
5. **用 GET 访问 POST 接口**：浏览器地址栏发的是 GET，登录接口是 POST → 报 `HttpRequestMethodNotSupportedException`。用 Postman/curl 发 POST 即可。
6. **拦截器路径写 `/api/console/` 缺 `**`**：只匹配路径本身，子路径全裸奔 → `/me` 走了"无拦截"分支；又叠加 `Map.of` 不允许 null 值（UserContext 为空时 NPE）→ 500 系统繁忙。教训：`**` = 任意多层子路径；`Map.of` 的 value 不能是 null。
7. **404/405 被兜底成 500**：GlobalExceptionHandler 的 `Exception.class` 大网把 NoResourceFound 等请求错误也包装成"系统繁忙"。后续需补充专门 handler（低优先级）。
