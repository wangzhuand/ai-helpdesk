### 待办 B：W5 详细计划（下一阶段主线）

**目标**：让系统"按意思找资料"，并让 AI 基于检索结果回答 + 标注来源。

1. **向量检索 kNN**：把用户问题用 `EmbeddingClient.embed()` 转向量 → 用 ES 的 `knn` 查询在 `kb_chunk` 里找最近的 k 条
   - Java 客户端写法思路：`esClient.search(s -> s.index("kb_chunk").knn(k -> k.field("embedding").queryVector(...).k(3).numCandidates(50)))`
   - 对比：`_source:false` 可避免把 1024 维向量捞回来
2. **混合检索（BM25 + 向量 + RRF）**：
   - 两路搜索：① `match` 查询 `content`（关键词，IK 分词）② `knn`（语义）
   - 融合：RRF（Reciprocal Rank Fusion，按排名倒数加权 `1/(k+rank)`）——**可在 Java 里手工合并两个结果列表**（更利于讲清原理、面试加分），也可用 ES 8.8+ 原生 `retriever.rrf`
   - 产出对比数据：关键词 / 向量 / 混合 三种方式的召回差异（W12 评测要用）
3. **回答带引用**：检索到的知识块带上 `doc_title`，拼进 prompt，要求 AI 在回答末尾标注「参考自《xxx》」
4. **检索测试接口**：`GET /api/console/kb/search-test?q=xxx&mode=keyword|vector|hybrid`，返回三路结果 + 分数（控制台"检索测试"页要用；也是演示亮点）

## 踩坑记录（面试素材，随做随记）

1. **主类包名拼错 `hepldesk` → 接口 404**：`@SpringBootApplication` 的 `@ComponentScan` 只扫描主类所在包及子包；所有业务类必须放在主类包正下方。
2. **Spring Initializr 向导无 3.x 选项**：向导联网 start.spring.io（被墙）且默认只给最新 4.x；改用手动 Maven + pom 写死 parent `3.5.3` 走阿里云镜像。生态组件对 4.x 适配未跟上，项目锁 3.5.x。
3. **LF/CRLF 换行警告**：Windows 与 Git 换行符差异，无害；可用 `.gitattributes`（`* text=auto`）统一，暂未加。
4. **登录报"密码错误"真相**：`CommandLineRunner` 只在启动时执行一次，改完 `DataInitializer` 没彻底重启（热重载不算）→ 占位密码没被替换。教训：启动初始化类代码必须完全停进程再启。
5. **用 GET 访问 POST 接口**：浏览器地址栏发 GET，登录接口是 POST → `HttpRequestMethodNotSupportedException`。
6. **拦截器路径写 `/api/console/` 缺 `**`**：只匹配路径本身 → 子路径全裸奔；叠加 `Map.of` 不允许 null（UserContext 空时 NPE）→ 500。
7. **404/405 被兜底成 500**：`Exception.class` 大网把请求错误也包装成"系统繁忙"（已补 `NoResourceFoundException` 处理器解决 404 部分）。
8. **前端报"网络错误"= 后端 8080 没启动**：排查顺序：先 `localhost:8080/api/health`，再看 F12 Console。
9. **跨域解法**：前端 vite proxy 把 `/api` 转发到 8080，浏览器只见同源，OPTIONS 预检消失（后端放行 OPTIONS 的逻辑保留）。
10. **GLM 接入连环坑（已转 DeepSeek）**：① 未实名 → key 全 401；② Git Bash 发中文 → GBK → 400 UTF-8 错误；③ Spring AI 默认拼 `/v1/chat/completions`，GLM 只认 `/v4/` → 404，需 `completions-path: /chat/completions`（该属性靠解 jar + javap 挖出）；④ `glm-4.7-flash` 免费模型持续 1305 繁忙。
11. **MySQL 8 报 `Public Key Retrieval is not allowed`**：JDBC URL 加 `allowPublicKeyRetrieval=true`。
12. **"找不到 ChatClient Bean"**：Spring AI 自动配置只给 `ChatClient.Builder`，需自建 `@Bean ChatClient`（`AiConfig`）。
13. **SSE 前端三坑**：① 网络把多个 token 打包到达 → 前端"打字机节奏器"（队列 + 每 15ms 吐一字）平滑播放；② **Vue3 响应式坑**：对象 push 进 ref 数组后，局部变量仍指向原始对象，改它不触发渲染 → 必须改 `messages.value[下标]`；③ Enter 发送/Shift+Enter 换行用 `@keydown.enter.exact.prevent`。
14. **流式接口协议**：SSE 事件 `visitor`(回执 JSON) → `token`(逐字) → `done`(完整消息 JSON) / `error`；前端用 `fetch`（非 axios）+ `ReadableStream`，帧按空行 `\n\n` 切分。
15. **云服务器踩坑（腾讯云 Ubuntu 26.04）**：① `get.docker.com`/`get.daocloud.io` 连不上（出站被过滤）→ 用阿里云 docker-ce apt 源（`noble` 套件在 26.04 也可用）；② **FinalShell 多行粘贴不可靠** → 一律单行命令；③ Docker Hub 直连卡死 → 配 `/etc/docker/daemon.json` 镜像加速；④ ES 需 `vm.max_map_count=262144`；⑤ **ES 启动要 1-3 分钟**，期间 curl 报 `Connection reset by peer`；⑥ ES 关了认证，**9200 绝不能裸开公网**。
16. **写 ES 报 `Connection refused` = SSH 隧道断了**（FinalShell 断开/休眠/切网都会发生）。注意向量化走公网不受影响，只有 ES 操作失败。**习惯：开工先 `curl http://localhost:9200`**。
17. **双写不一致首次现身**：先写 MySQL 后写 ES，ES 失败后 MySQL 留下孤儿 `kb_chunk`、文档状态 FAILED。W7/W11 处理（重试、清理、对账）。
18. **SLF4J 占位符**：`log.error("id=", doc.getId(), e)` 不填值，必须写 `id={}`。
19. **ES 客户端 API 心法**：看不懂 Java 客户端时，先翻译回 curl（`esClient.index(...)` = `PUT /索引/_doc/{id}`）。
20. **IK 中文分词器安装**：ES 8 的 IK 插件必须与 ES 版本完全一致；服务器出站受限 → 在本地下载 zip → FinalShell SFTP 上传 → `docker cp` 进容器 → `bin/elasticsearch-plugin install file:///tmp/ik.zip` → 重启容器。验证：`_analyze` 指定 `analyzer: ik_max_word` 看是否按词切分。
21. **ES 索引设计要点**：`content` 用 `text` + `ik_max_word`(索引侧)/`ik_smart`(查询侧)；`keyword` 用于精确匹配；单节点下 `number_of_replicas: 0` 才是 green；`dense_vector` 的 `dims` 必须等于 embedding 模型输出维度（本项目 1024）；字段新增可以、改类型/维度只能重建索引。
